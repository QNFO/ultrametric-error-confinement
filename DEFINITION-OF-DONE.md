### Archive Cross-Reference

This demo visualizes data produced by:
- **ultrametric_v2** (Archive 2026/05) — simulation pipeline with 45 files, created the error rate vs depth data, hardware specifications, and QEC concatenation results
- **Validation of Ultrametric Error Confinement** (Archive 2026/05 → DOI: 10.5281/zenodo.20134944) — first computational validation paper
- **Symmetric Extension of Ultrametric Error Confinement** (Archive 2026/05 → DOI: 10.5281/zenodo.20208437) — formal proof of 48× error reduction

The data shown in the Evidence Deck charts (LER vs depth, error reduction vs encoding size) was generated by ultrametric_v2's simulation pipeline (0.2.py through 0.16_qec_concatenation.py). The zero errors at depth 7 result was first published in Validation of Ultrametric Error Confinement. The 48× reduction at q=128 was first published in Symmetric Extension.
