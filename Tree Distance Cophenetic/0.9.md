# Empirical Test Design: Triadic Rigidity as Signature of Hierarchical Organization

**Version:** 0.9
**Date:** 2026-05-15
**Status:** Draft — research design, not yet executed
**Parent framework:** Tree Distance Cophenetic (0.8.md)

---

## 1. Motivation

The Tree Distance Cophenetic framework (0.8.md) makes a specific, falsifiable claim:

> Where the ultrametric inequality holds (and triadic rigidity is observed), the domain is hierarchically organized. Where it fails, other structures apply.

This is a powerful claim — but it has not been empirically tested outside of synthetic tree data. The framework's CGF self-evaluation (0.8.md §5.2) identifies "Evidential Coherence" as its weakest dimension (3.3/5), noting:

> "Physics and cognitive connections not empirically validated."

This document proposes three empirical tests, ordered by feasibility, that would begin to close the evidence gap. Each test is designed to be executable with publicly available data and standard Python tooling.

### What Triadic Rigidity Tests

For any three items $x, y, z$ with pairwise distances $d_1 \geq d_2 \geq d_3$:

$$\text{Triadic rigidity holds} \iff d_1 = d_2$$

In a purely hierarchical domain (where items are organized by nested equivalence relations), this equality must hold for every triple. In a non-hierarchical domain (e.g., Euclidean space), it generally fails. The **fraction of triples satisfying triadic rigidity** is therefore a detector of hierarchical organization.

## 2. Test A: Phylogenetic Sanity Check

**Difficulty:** Trivial (theorem guarantees 100%)
**Value:** Establishes baseline, validates methodology, generates intuition

### Design

1. Obtain 5–10 published phylogenetic trees (mammals, birds, plants, languages) from public repositories (TreeBASE, Glottolog, Zenodo).
2. For each tree, compute the cophenetic distance matrix and verify:
   - All triples satisfy the ultrametric inequality — must be 100% (theorem)
   - All triples satisfy triadic rigidity — must be 100% (theorem)
3. Introduce controlled perturbations:
   - Randomly perturb node heights by $\pm \delta$ (uniform noise)
   - Measure: at what $\delta$ (relative to mean node height) does triadic rigidity break for >1% of triples?
4. Compare noise tolerance across trees with different topologies (bushy vs. ladder-like).

### Success Criterion
All unperturbed trees show 100% triadic rigidity. Noise tolerance varies by topology but is non-zero — the signal is robust to modest measurement error.

### Why This Matters
Demonstrates that triadic rigidity is not just a theorem about idealized trees — it's a **practically measurable property** that survives real-world noise. Establishes confidence in the metric before applying it to unknown domains.

## 3. Test B: Hierarchy Detection Benchmark

**Difficulty:** Medium (requires synthetic data generation)
**Value:** HIGH — directly tests the framework's falsifiable claim

### Design

**Step 1: Generate labeled datasets**

| Dataset | Structure | Ground Truth | Size |
|:--------|:----------|:-------------|:-----|
| D1 | Items generated from a known rooted tree with random leaf perturbations | Hierarchical | 50 items |
| D2 | Items from a Gaussian mixture model (3 clusters in $\mathbb{R}^2$) | Partially hierarchical | 50 items |
| D3 | Items uniformly distributed in $\mathbb{R}^2$ | Non-hierarchical (Euclidean) | 50 items |
| D4 | Items from a social network (random graph, shortest-path distance) | Network (non-tree) | 50 items |
| D5 | Items from a known tree + strong noise (leaf positions jittered 50% of tree height) | Weakly hierarchical | 50 items |

**Step 2: For each dataset, compute:**

- Pairwise distance matrix (Euclidean for D1-D3, shortest-path for D4, cophenetic for D5)
- For all $\binom{n}{3}$ triples, sort distances $(d_1, d_2, d_3)$ and test $|d_1 - d_2| < \epsilon$ for a tolerance $\epsilon$
- Compute **Triadic Rigidity Index (TRI)**:

$$\text{TRI} = \frac{\text{number of triples where } |d_1 - d_2| < \epsilon \cdot \bar{d}}{\binom{n}{3}}$$

where $\bar{d}$ is the mean pairwise distance (scale-invariant tolerance).

**Step 3: Evaluate**

| Dataset | Expected TRI | Interpretation |
|:--------|:-------------|:---------------|
| D1 (tree) | $\approx 1.0$ | Perfect hierarchy |
| D2 (Gaussian mixture) | $0.3$–$0.7$ | Partial hierarchy (clusters are nested within higher-level groupings) |
| D3 (uniform) | $\approx 0$ | No hierarchy |
| D4 (network) | $0$–$0.3$ | Network distances are additive, not nested |
| D5 (noisy tree) | $0.5$–$0.9$ | Depends on noise level — measures robustness |

**Statistical test:** Use a permutation test for each dataset — shuffle distance labels and recompute TRI. Compare observed TRI to null distribution. Report $p$-value and effect size (Cohen's $d$ between observed TRI and null mean).

### Success Criteria

1. **Discrimination:** D1 TRI $\gg$ D3 TRI (hierarchical vs. non-hierarchical clearly separated)
2. **Gradation:** D2 TRI falls between D1 and D3 (detects partial hierarchy)
3. **Robustness:** D5 TRI varies monotonically with noise level
4. **Specificity:** D4 TRI is low (network structure does not falsely trigger hierarchy detection)

See `0.9.py` for a working implementation of Test B with synthetic data generation, TRI computation, and statistical testing.

## 4. Test C: Resolution-Dependence

**Difficulty:** High (requires real longitudinal or multi-scale data)
**Value:** HIGH — tests the ε-bridge (§3.1 of 0.8.md)

### Design

The framework claims: "tree depth = resolution parameter $\varepsilon$." This implies a specific relationship:

> As resolution increases (finer $\varepsilon$), more items become distinguishable, and the cophenetic distance between any pair decreases toward zero.

**Operationalization:**

Find a domain where the same set of items can be measured at multiple resolutions:
- **Option 1: Genomics.** Gene sequence similarity at different alignment thresholds. At coarse resolution, all mammals cluster together; at fine resolution, species separate.
- **Option 2: Linguistics.** Word similarity at different cognate thresholds. At coarse resolution, all Indo-European languages cluster; at fine resolution, Germanic vs. Romance separate.
- **Option 3: Image analysis.** Pixel color clustering at different quantization levels.

**Procedure:**
1. Select a domain with natural resolution hierarchy.
2. At each of $k$ resolution levels, construct a dendrogram and compute TRI.
3. Test two predictions:
   - **P1:** TRI increases toward 1.0 as resolution increases (more hierarchical structure becomes visible)
   - **P2:** The tree depth at which two items first separate (their cophenetic distance) is invariant to further resolution increase (the ontic invariant claim)

### Success Criterion
P1 holds with statistical significance. P2 holds — items that separate at depth $h$ at one resolution do not "re-merge" at finer resolutions.

## 6. What a Failed Test Would Mean

**If Test B shows TRI $\approx 0$ for Dataset D1 (known tree):** The methodology is flawed — cophenetic distance was miscalculated. Debug.

**If Test B shows TRI $\approx 1$ for Dataset D3 (Euclidean uniform):** Triadic rigidity is trivially common and not a useful detector. The framework's falsifiability claim is undermined.

**If Test B shows TRI $\approx 1$ for Dataset D4 (network):** Network distances can be ultrametric — the framework's claim that triadic rigidity distinguishes hierarchical from non-hierarchical is too strong.

**If Test B discriminates correctly but Test C fails:** The ε-bridge is not empirically supported. The framework remains a useful mathematical tool for hierarchy but the physical/philosophical extensions are unjustified.

**All of these are valuable outcomes.** Falsification is progress.
