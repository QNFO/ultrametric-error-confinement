## 3. W1: Empirical Deficit

### Current State

The framework makes a falsifiable claim — "where triadic rigidity fails, the domain is not purely hierarchical" — but no domain outside of synthetic tree data has been tested. CGF Evidential Coherence is the framework's weakest dimension at 3.3/5.

### Action A1: Execute Test B on Real Data

**What:** Apply the TRI benchmark from 0.9.py to a real dataset with known hierarchical structure.

**Candidate datasets:**
| Domain | Dataset | Why |
|:-------|:--------|:----|
| Phylogenetics | Mammal supertree (Bininda-Emonds et al., 2007) | Published tree with ~4,500 species — compute cophenetic distances, verify TRI = 1.000 |
| Linguistics | Indo-European cognate database (IELex, Dunn et al.) | Language families are trees — lexicostatistical distances should be approximately ultrametric |
| Clustering | UCI benchmark datasets (Iris, Wine, Digits) | Hierarchical clustering on known benchmarks — TRI should be high for datasets with natural hierarchy |

**Success criteria:**
- Real phylogenetic tree → TRI $\geq$ 0.95 (near-perfect hierarchy, accounting for measurement noise)
- UCI datasets with known cluster structure → TRI significantly above random baseline ($p < 0.05$)
- Euclidean/random baselines → TRI near 0 (replicate 0.9.py results)

**Effort:** Medium (requires data import, cleaning, distance computation)
**Status:** Prototype exists (0.9.py); needs real data

### Action A2: Design Domain-Specific Empirical Test

**What:** Go beyond hierarchy detection to test a specific prediction of the framework in one domain.

**Candidate domains and predictions:**

| Domain | Testable Prediction | Method |
|:-------|:--------------------|:--------|
| **Phylogenetics** | Species within the same genus have cophenetic distances clustered at genus-level node heights | Compare within-genus vs. between-genus distance distributions |
| **Social networks** | Friend groups with clear hierarchy (e.g., corporate org charts) show higher TRI than flat networks | Collect org chart data; compute network distances; test TRI |
| **Cognitive psychology** | Human similarity judgments for hierarchical categories (e.g., animal taxonomy) show higher TRI than for non-hierarchical categories (e.g., color perception) | Reanalyze published similarity-rating datasets |

**Success criteria:** At least one domain shows TRI significantly above chance ($p < 0.01$), with effect size Cohen's $d > 1.0$.

**Effort:** High (requires domain expertise, data collection, experimental design)
**Status:** Not started

## 4. W2: Physics Minority Position

### Current State

The Page-Wootters construction is not the mainstream approach to quantum gravity. The CGF notes: "Page-Wootters is minority position in quantum gravity" as a constraint on Scientific Coherence. A physicist encountering the framework may dismiss the §3 bridge on these grounds before engaging with the mathematical core.

### Action A3: Cite Alternative Physics Frameworks

**What:** Show that the tree framework is not dependent on Page-Wootters specifically — the structural analogy works with any framework that separates timeless structure from emergent dynamics.

**Alternative frameworks to cite:**

| Framework | Core Idea | Tree Analogy |
|:----------|:----------|:-------------|
| Barbour's Shape Dynamics | Time emerges from relational change in a timeless configuration space | Tree topology = timeless configuration space; tree traversal = emergent time |
| Rovelli's Relational QM | States are relations between systems, not absolute properties | Tree branching = relational distinctions; height = relational distance |
| 't Hooft's Cellular Automaton Interpretation | Quantum mechanics emerges from deterministic cellular automaton at Planck scale | Tree cuts = cellular automaton state transitions; hierarchy = computational depth |

**Implementation:** Add a subsection to 0.8.md §3 noting these alternative mappings. This demonstrates that the tree framework is agnostic to which specific physics framework is correct — the structural pattern (timeless hierarchy + emergent traversal) is what matters.

**Effort:** Low (1-2 paragraphs)
**Status:** Not started

### Action A4: Strengthen Caveat Language in §2.6

**What:** The current caveat in §2.6 already says: "This is a structural analogy, not a formal derivation." But it could be strengthened to pre-empt dismissal.

**Proposed rewording:**

> **Caveat (strengthened):** This is a structural analogy, not a formal derivation. The tree framework does not produce a Hamiltonian, a Hilbert space, or testable quantum-gravitational predictions. The analogy maps the **logical structure** — timeless invariant + emergent conditional dynamics — not the physical mechanisms. The framework does not depend on Page-Wootters being correct; it only requires that *some* separation of timeless structure from emergent dynamics exists. The tree is a candidate for what that timeless structure might be.

**Effort:** Very low (edit existing paragraph)
**Status:** Not started

## 6. W4: Reader Accessibility

### Current State

CGF identifies: "No glossary or accessible introduction. Sections 3–4 assume QNFO familiarity." The §1.4 Reading Guide is honest about prerequisites, but the framework still presents barriers to readers without QNFO background.

### Action A5: Create Glossary

**What:** Add a glossary of terms to 0.8.md (or as a standalone appendix).

**Terms to define:**

| Term | Domain | Definition |
|:-----|:-------|:-----------|
| Cophenetic distance | Math | $d(x, y) = h(\operatorname{lca}(x, y))$ — the height of the lowest common ancestor of two leaves |
| Ultrametric inequality | Math | $d(x, z) \leq \max(d(x, y), d(y, z))$ — stronger than the triangle inequality |
| Triadic rigidity | Math | For any three items, the two largest pairwise distances are equal |
| Gauge invariance | Physics/Math | The branching order is invariant; numerical distances are conventional |
| Wheeler-DeWitt equation | Physics | $\hat{H}|\Psi\rangle = 0$ — the timeless quantum state of the universe |
| Page-Wootters construction | Physics | Internal clock variable extracts conditional dynamics from a stationary state |
| Autaxys | QNFO | The irreducible drive toward self-organization — the generative mechanism |
| IOT / $\varepsilon$ / $\kappa$ / $\tau$ | QNFO | Illusion of Time terminology (resolution, contrast, temporal sequence) |
| Ontic / Epistemic | Philosophy | Ontic = what exists independently (tree topology); epistemic = what depends on observation (numerical distances) |
| 5I Process | Methodology | Identify, Ideate, Interrogate, Implement, Iterate |

**Effort:** Low (write glossary once, reference throughout)
**Status:** Not started

### Action A6: Write Accessible Introduction

**What:** Create a standalone document (`0.11.md`?) that introduces the framework assuming only undergraduate-level mathematics. No QNFO terminology. No physics references.

**Structure:**
1. The intuition: "Two items are close when they stay together through many cuts..."
2. Concrete example: 4-item dendrogram with A, B, C, D
3. The ultrametric inequality explained with the example
4. Why this matters: it distinguishes hierarchy from other structures
5. Where to go next: link to 0.8.md for full treatment

**Effort:** Medium (2-3 page document)
**Status:** Not started

### Action A7: Add Visual Diagrams

**What:** Create tree structure diagrams for §§1-2 of 0.8.md.

**Needed diagrams:**

**Effort:** Medium (ASCII for now, publication-quality later)
