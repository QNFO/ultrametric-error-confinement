## API

### Tree(n_leaves, height_function, parent)

| Method | Returns | Description |
|:-------|:--------|:------------|
| `cophenetic_distance(x, y)` | float | $d(x, y) = h(\operatorname{lca}(x, y))$ |
| `distance_matrix()` | list[list[float]] | Full $n \times n$ distance matrix |
| `check_ultrametric()` | bool | Verifies $d(x,z) \leq \max(d(x,y), d(y,z))$ for all triples |
| `triadic_rigidity()` | float | Fraction of triples where $d_1 = d_2$ |
| `lca(x, y)` | int | Lowest common ancestor of leaves $x$ and $y$ |

### Static Methods

| Method | Returns | Description |
|:-------|:--------|:------------|
| `Tree.demo_dendrogram()` | Tree | 4-item red/blue large/small example |
| `Tree.euclidean_counterexample()` | bool | True if NYC-Philly-Boston violates triadic rigidity |
