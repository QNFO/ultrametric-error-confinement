## Diagram 1: The Four-Item Dendrogram

Items: A (Red-Large), B (Red-Small), C (Blue-Large), D (Blue-Small)
Cuts: First by color (coarse), then by size (fine) within each color.

```
                     HEIGHT
                       ^
                       |
        h=5            @ (root: ALL ITEMS)
                      / \
                     /   \
        h=3         @     @  (color cut: RED vs BLUE)
                   / \   / \
                  /   \ /   \
        h=0      A     B     C     D
                (RL)  (RS)  (BL)  (BS)

    Cophenetic distance matrix D:
          A    B    C    D
       A  0    3    5    5
       B  3    0    5    5
       C  5    5    0    3
       D  5    5    3    0

    Interpretation:
      d(A,B) = 3  -- same color, different size (close)
      d(C,D) = 3  -- same color, different size (close)
      d(A,C) = 5  -- different color (far)
      d(A,D) = 5  -- different color (far)
```

**Key:** The cophenetic distance $d(x, y)$ is the height of the **lowest common ancestor** (LCA) of $x$ and $y$. For A and B, the LCA is the "RED" node at height 3. For A and C, the LCA is the root at height 5.

## Diagram 2: Lowest Common Ancestor (LCA)

Three leaves (A, C, D) with their paths to the root. The LCA is where
two paths first meet.

```
                    @ ROOT (h=5)
                   / \
                  /   \
                 @     @  (h=3)
                / \   / \
               A   B C   D   (h=0)

    Finding LCA(A, C):
      Path of A:  A --> @(h=3) --> @(h=5)
      Path of C:  C --> @(h=3) --> @(h=5)
      First meeting point: @(h=5) = ROOT
      Therefore: lca(A, C) = ROOT, d(A, C) = 5

    Finding LCA(C, D):
      Path of C:  C --> @(h=3) --> @(h=5)
      Path of D:  D --> @(h=3) --> @(h=5)
      First meeting point: @(h=3) = BLUE node
      Therefore: lca(C, D) = BLUE node, d(C, D) = 3
```

**Key insight:** Items that share a deeper LCA (closer to the leaves) are more similar. Items whose LCA is the root are maximally dissimilar.

## Diagram 3: Triadic Rigidity — Equal Longest Sides

For any THREE items in a hierarchical tree, the TWO LARGEST pairwise
distances are EQUAL. All triangles are "acute isosceles."

```
    Example triple {A, B, C} from the dendrogram:
      d(A,B) = 3  (same color, different size)
      d(A,C) = 5  (different color)
      d(B,C) = 5  (different color)

      Sorted: d1=5, d2=5, d3=3
      TWO LARGEST: d1=5 and d2=5 --> EQUAL! ✓

    Visual:
           A
           |\
           | \
       3   |  \   5     The two LONG sides are equal.
           |   \        This ALWAYS happens in a tree.
           |    \
           B-----C
             5

    Another triple {A, B, D}:
      d(A,B)=3, d(A,D)=5, d(B,D)=5
      Sorted: 5, 5, 3 --> two largest equal ✓
```

**Why?** In a rooted tree, among any three leaves, at least two share a
deeper LCA than the third pair. Those two pairs have the same (larger)
distance. The third pair has a strictly smaller distance.

## Diagram 4: Euclidean Counterexample — Triadic Rigidity FAILS

In ordinary Euclidean space, triadic rigidity DOES NOT hold.
Here's a concrete counterexample:

```
    Three cities on the US East Coast:
      NYC (New York)
      PHL (Philadelphia)
      BOS (Boston)

    Approximate straight-line distances:
      d(NYC, PHL) = 150 km
      d(NYC, BOS) = 350 km
      d(PHL, BOS) = 500 km

    Sorted: d1=500, d2=350, d3=150
    TWO LARGEST: 500 and 350 --> NOT EQUAL ✗

    Visual triangle (not to scale):
              BOS
              /|
             / |
       500  /  |  350     All three sides are DIFFERENT.
           /   |         This is a SCALENE triangle.
          /    |         Impossible in a tree-based space!
         PHL---NYC
           150
```

**Implication:** Geographic space is NOT purely hierarchical. This
distinguishes spatial organization from tree-based organization.
Triadic rigidity is a **falsifiable test** — if it fails, the domain
contains non-hierarchical structure.

## Diagram 5: Height Function and Cophenetic Distance

The **height function** $h(v)$ maps each node to a non-negative number.
Leaves have height 0. The root has the MAXIMUM height. Height increases
as we move UP the tree (toward the root).

```
    Height values annotated on each node:

              h=5  [ROOT]
                   / \
                  /   \
             h=3 [C1]  [C2] h=3
                 / \    / \
                /   \  /   \
           h=0 A    B C    D h=0

    Cophenetic distance: d(x, y) = h( lca(x, y) )

              lca(A,B) = [C1] --> h(C1) = 3 --> d(A,B) = 3
              lca(A,C) = [ROOT] -> h(ROOT)= 5 --> d(A,C) = 5
              lca(C,D) = [C2] --> h(C2) = 3 --> d(C,D) = 3
```

**Interpretation:** Height measures dissimilarity depth — how "deep"
a cut lies in the hierarchy. Larger height = coarser, earlier distinction.
Leaves are at h=0 because items at the same leaf are identical.

## Diagram 6: Binary Decomposition

Any multi-way branching can be decomposed into binary (yes/no) splits.
This means binary distinctions are the "atoms" of hierarchical organization.

```
    Ternary split (3-way):            Binary decomposition (2 splits):

         @ (h=8)                           @ (h=8)
        /|\                               / \
       / | \                             /   \
      A  B  C                        @(h=5)  C
                                     / \
                                    /   \
                                   A     B

    Cophenetic distances preserved:
      Ternary: d(A,C)=8, d(B,C)=8, d(A,B)=5
      Binary:  d(A,C)=8, d(B,C)=8, d(A,B)=5
      --> IDENTICAL distance matrix!
```

**Principle:** A k-way split equals k-1 binary splits. Binary
distinctions (yes/no questions) are the minimal unit of information.
This is why binary trees are universal representational structures
for hierarchical data.

## Diagram 7: Not Everything Is a Tree

Triadic rigidity provides a clear boundary between what IS and IS NOT
hierarchically structured:

```
    HIERARCHICAL (triadic rigidity HOLDS):
      - Phylogenetic trees
      - Organizational charts
      - Hierarchical clustering
      - Nested equivalence relations
      - Language family trees

         @         All triangles are isosceles
        / \        with two equal longest sides.
       @   @
      / \ / \
     A  B C  D        d1 = d2  ✓

    NON-HIERARCHICAL (triadic rigidity FAILS):
      - Geographic space
      - Social networks (shortest-path distance)
      - Random graphs
      - Uniform Euclidean space

      A ●                    d1 ≠ d2  ✗
         \       All three distances
          \      can be different.
           \
       B ●---● C
```

**Falsifiable claim:** Measure pairwise distances in ANY domain. If
triadic rigidity holds, the domain has tree structure. If it fails,
it contains non-hierarchical organization.
