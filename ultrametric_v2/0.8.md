# Symmetric Extension of Ultrametric Error Confinement—Ternary Tree Architecture with Bidirectional Validation

**Rowan Brad Quni-Gudzinas**
*Independent Researcher*

**Companion to:** Quni-Gudzinas, "Computational Validation of Ultrametric Error Confinement in Bruhat–Tits Tree Quantum Circuits," Zenodo, 2026. DOI: [10.5281/zenodo.20134944](https://doi.org/10.5281/zenodo.20134944).

---

## Abstract

The Bruhat–Tits tree validation [1] used $p = 2$ (binary tree: root has $3$ children, internal nodes have $2$ children) and reported zero logical errors at depths $d \geq 3$ for error rates up to $p_{\text{err}} = 0.40$. However, that architecture contains an unrecognized structural asymmetry: when encoded as logical $1$, each internal node with $2$ children flips with a **single** leaf-flip (because tie-breaking favors $0$), yielding a constant energy barrier $B_{p=2,\,b=1}(d) = 2$ for all $d \geq 1$. Logical $0$ enjoys an exponential barrier $B_{p=2,\,b=0}(d) = 2^d$; logical $1$ is essentially unprotected at all depths.

We resolve this by switching to $p = 3$ (ternary tree, all nodes have exactly $3$ children). With odd branching at every node, majority is always $2$-of-$3$, eliminating all tie-breaking. We independently test both logical states and confirm **perfect symmetry**: identical logical error rates at every $(d, p_{\text{err}})$ data point. At $d = 7$ ($2{,}187$ leaves), we observe zero logical errors across $36{,}000$ total trials at all $p_{\text{err}} \leq 0.40$ (Wilson 95% CI upper bound: $0.0019$). We extend the validation to $d = 8$, provide constructive barrier proof through $d = 15$, and scope five physical platforms, identifying neutral atom tweezer arrays as the most promising near-term pathway ($d = 3$, $40$ atoms, existing hardware).

## 1. The $p = 2$ Asymmetry Problem

### 1.1 How Tie-Breaking Creates One-Sided Protection

The original Bruhat–Tits tree validation [1] used $p = 2$: the root node has $p + 1 = 3$ children, while all internal nodes have $p = 2$ children. Majority-vote decoding at internal nodes with $2$ children breaks ties to $0$ by convention. This is not an arbitrary choice—some convention is required when votes split evenly—but it creates a structural asymmetry between the two logical states.

Consider a single internal node with $2$ leaf children, encoding bit $b$:

**Encoded as $b = 0$ (children: $0, 0$):**

| Leaf errors | Child values | Tie-break | Node result | Flipped? |
|:-----------|:-------------|:---------|:------------|:---------|
| 0 errors | $(0, 0)$ | No tie | $0$ | No |
| 1 error | $(0, 1)$ or $(1, 0)$ | Tie $\to$ $0$ | $0$ | **No** |
| 2 errors | $(1, 1)$ | No tie | $1$ | Yes |

**Flipping this node requires $2$ leaf errors.** The tie-breaker protects logical $0$: even when one child is corrupted, the node output remains $0$.

**Encoded as $b = 1$ (children: $1, 1$):**

| Leaf errors | Child values | Tie-break | Node result | Flipped? |
|:-----------|:-------------|:---------|:------------|:---------|
| 0 errors | $(1, 1)$ | No tie | $1$ | No |
| 1 error | $(0, 1)$ or $(1, 0)$ | Tie $\to$ $0$ | $0$ | **Yes** |
| 2 errors | $(0, 0)$ | No tie | $0$ | Yes |

**Flipping this node requires only $1$ leaf error.** The tie-breaker betrays logical $1$: the moment one child is corrupted, the tie (now $0,1$) breaks to $0$, which is the *wrong* value.

### 1.2 Barrier Collapse for Logical $1$

This asymmetry propagates recursively. For the full $p = 2$ tree of depth $d$:

**Barrier when encoded as $b = 0$:**

$$B_{b=0}(1) = 2, \qquad B_{b=0}(d) = 2 \cdot B_{b=0}(d-1) = 2^d \quad (\text{for } d \geq 2)$$

Each internal node requires both children to flip, so the barrier doubles at each level—exponential protection.

**Barrier when encoded as $b = 1$:**

$$B_{b=1}(1) = 2 \quad (\text{root with 3 leaves needs 2 flips}), \qquad B_{b=1}(d) = 2 \quad (\text{for all } d \geq 2)$$

At $d \geq 2$, each internal node flips with a **single** leaf error (Table 2 above). The root sees $3$ children and requires $2$ of them to flip. Since any child can be flipped with $1$ leaf error, the root flips with just $2$ leaf errors total—**at any depth**. The barrier is constant, independent of depth. Logical $1$ receives essentially no protection from the tree structure.

**Exhaustive verification (all $2^n$ leaf patterns enumerated):**

| Depth | $n$ leaves | $B_{b=0}(d)$ | $B_{b=1}(d)$ | Ratio |
|:------|:-----------|:-------------|:-------------|:------|
| 1 | 3 | 2 | 2 | 1:1 |
| 2 | 6 | 4 | **2** | 2:1 |
| 3 | 12 | 8 | **2** | **4:1** |
| 4 | 24 | 16 | **2** | **8:1** |
| 7 | 192 | 128 | **2** | **64:1** |

All values for $d = 1, 2, 3$ confirmed by exhaustive enumeration over all $2^n$ leaf patterns. Higher depths follow from the recurrence.

### 1.3 What This Means for the Original Validation

The original $p = 2$ results [1]—zero logical errors at $d \geq 3$ for $p_{\text{err}} \leq 0.40$—are **valid for the state that was tested** (logical $0$). The exponential barrier for $b = 0$ is real. However, logical $1$ was never tested independently. Had it been, the constant barrier ($B = 2$) would have produced near-random logical error rates at all depths—the error confinement would not have been bidirectional.

This is not a flaw in the original's data or methodology. The asymmetry was structurally built into the $p = 2$ tree architecture. The contribution of this companion paper is to identify the asymmetry, resolve it, and provide the first fully symmetric validation.

## 2. The Ternary ($p = 3$) Solution

### 2.1 Why $p = 3$ Eliminates Asymmetry

By switching to $p = 3$, every node (including the root) has exactly $3$ children. With odd branching:

- Majority requires $2$ of $3$ children ($\lceil 3/2 \rceil = 2$).
- **No ties are possible** at any node (odd number of inputs).
- The decision rule is identical at every level and for both logical states.

| Node type | Children | Rule | Ties? | Barrier contribution |
|:----------|:---------|:-----|:------|:---------------------|
| Root (original $p=2$) | 3 | Majority $\geq 2$ | No | 2 |
| Internal (original $p=2$) | 2 | Tie $\to$ $0$ | **Yes** | 2 (for $b=0$), **1** (for $b=1$) |
| All nodes ($p=3$) | 3 | Majority $\geq 2$ | **No** | 2 (both $b=0,1$) |

The barrier recurrence for $p = 3$ is symmetric:

$$B_{p=3}(1) = 2, \qquad B_{p=3}(d) = 2 \cdot B_{p=3}(d-1) = 2^d \quad (\text{for both logical states})$$

### 2.2 Comparison of Barrier Scaling

**Table: Energy barrier $B(d)$ by architecture and logical state**

| Depth $d$ | Leaves ($p=2$) | Leaves ($p=3$) | $B_{p=2,\,b=0}$ | $B_{p=2,\,b=1}$ | $B_{p=3}$ (both) |
|:----------|:---------------|:---------------|:-----------------|:-----------------|:-----------------|
| 1 | 3 | 3 | 2 | 2 | 2 |
| 2 | 6 | 9 | 4 | **2** | 4 |
| 3 | 12 | 27 | 8 | **2** | 8 |
| 4 | 24 | 81 | 16 | **2** | 16 |
| 5 | 48 | 243 | 32 | **2** | 32 |
| 7 | 192 | 2,187 | 128 | **2** | 128 |
| 10 | 1,536 | 59,049 | 1,024 | **2** | 1,024 |

The $p = 3$ tree requires more leaves ($3^d$ vs. $3 \cdot 2^{d-1}$), but this is the cost of **genuine bidirectional protection**. The $p = 2$ architecture cannot protect logical $1$ at any depth—its barrier stays at $2$ regardless of how deep the tree grows.

### 2.3 Deviation from Strict Bruhat–Tits

Root degree is $3$ not $p+1 = 4$. This is deliberate: a root with $4$ children would re-introduce even-count tie scenarios ($2$–$2$ votes). The tree remains an ultrametric space; all results hold for any rooted subtree of the full Bruhat–Tits tree.

## 3. Methods

### 3.1 Encoding, Decoding, and Error Model

Identical in structure to [1]: encode all leaves to $b \in \{0, 1\}$, apply i.i.d. bit-flip noise with probability $p_{\text{err}}$ to leaves only, decode via bottom-up majority vote (classical post-processing). Implementation: Python 3.10+, standard library only, seed = 42.

### 3.2 Experimental Design

| Parameter | Original [1] ($p=2$) | This Work ($p=3$) |
|:----------|:---------------------|:-------------------|
| Depths tested | $d = 2, 3, 4, 5$ | $d = 2, 3, 4, 5, 6, 7, 8$ |
| Logical bits tested | 1 (bit $0$ only) | 2 (bits $0$ and $1$, independent) |
| Trials per condition | 500 | 500 ($d \leq 5$), 1,000 ($d = 6, 8$), 2,000 ($d = 7$) |
| Confidence intervals | Wilson 95% CI | Wilson 95% CI |

For depths $\geq 7$, the symmetric architecture outperforms the asymmetric one on the metric that matters: bidirectional protection.

## 5. Physical Implementation Pathway

The original paper [1] proposed a twisted Bi-2212 superconducting substrate but did not evaluate near-term experimental platforms.

### 5.1 Platform Recommendation

**Neutral atom tweezer arrays** are the most promising platform: arbitrary 2D/3D geometry, Rydberg-mediated interactions with tunable range, demonstrated scaling to $1{,}000+$ atoms, and detectable atom loss (erasure errors). Trapped ions are a viable secondary option for small-scale proof-of-principle.

### 5.2 Near-Term Demonstration ($d = 3$, 40 atoms)

Requires 40 atoms, controlled error injection, fluorescence readout, and classical post-processing. **No ancilla qubits, syndrome measurement, or real-time feedback.** Feasible on existing platforms (Harvard/Lukin–Greiner, Caltech/Endres, Pasqal/Browaeys).

## 6. Discussion

### 6.1 Why the Ternary Architecture Is the Correct Generalization

The original $p=2$ architecture [1] is not "wrong"—it is **incomplete**. The error confinement mechanism (exponential barrier via hierarchical majority voting) is real and was correctly identified. But the architecture cannot provide bidirectional protection because internal tie-breaking inherently favors one logical state.

The $p=3$ architecture generalizes the mechanism to a symmetric form: every node uses the same rule, no ties occur anywhere, and both logical states receive identical exponential protection. The barrier exponent is unchanged between architectures—only the asymmetry is removed.

### 6.2 The Barrier Scaling Is Identical

Critically, the symmetry fix does **not** weaken the exponential barrier. For both $p = 2$ (bit $0$ only) and $p = 3$ (both bits):

$$B(d) = \lceil p/2 \rceil^d = 2^d$$

The ternary tree requires more leaves at each depth ($3^d$ vs. $3 \cdot 2^{d-1}$), but the barrier exponent is unchanged. The only thing sacrificed is the illusory "zero errors at $d \geq 3$" that appeared in the original because only the favored state was tested.

### 6.3 Relationship to the Original Validation

This companion paper does not contradict the original [1]; it **completes** it:

| Original [1] Demonstrated | This Companion Adds |
|:--------------------------|:--------------------|
| Error confinement **mechanism** | **Bidirectional** confinement |
| Zero errors at $d \geq 3$ for favored state | Zero errors at $d \geq 7$ for **both** states |
| Exponential barrier for $b=0$ | Exponential barrier for **both** bits |
| Theoretical motivation | Physical implementation scoping |
| 500 trials per condition | Up to 2,000 trials, tighter CIs |

### 6.4 Limitations

In addition to the limitations enumerated in [1]:

1. **$p = 3$ is less qubit-efficient than $p = 2$:** The leaf count grows as $3^d$ rather than $3 \cdot 2^{d-1}$. At $d = 10$: $59{,}049$ leaves ($p = 3$) vs. $1{,}536$ leaves (original $p = 2$, which only protects one bit). This is the price of genuine bidirectional symmetry.
2. **Phase errors unaddressed:** As with the original, only bit-flip errors are considered.
3. **Platform assessments are theoretical:** All platform evaluations are $[\text{LLM-INFERRED}]$ and should be verified with experimental collaborators.

## 7. Conclusion

We have identified and resolved a fundamental asymmetry in the $p = 2$ Bruhat–Tits tree architecture [1]: when encoded as logical $1$, internal tie-breaking collapses the energy barrier from $2^d$ to a constant $2$ at all depths, leaving logical $1$ essentially unprotected. The $p = 3$ ternary tree architecture eliminates this asymmetry by using odd branching everywhere, restoring full bidirectional protection with identical exponential barrier scaling $B(d) = 2^d$ for both logical states.

Our extended validation ($d = 2\ldots 8$, up to $2{,}000$ trials per condition) demonstrates zero logical errors at $d \geq 7$ for **both** bits at all tested error rates $p_{\text{err}} \leq 0.40$, confirmed by Wilson 95% confidence intervals. We have identified neutral atom tweezer arrays as the most promising near-term implementation platform and outlined a concrete $d = 3$, $40$-atom demonstration feasible on existing hardware.
