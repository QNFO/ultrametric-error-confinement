## Abstract

The original Bruhat-Tits tree validation [1] used $p = 2$ (binary tree, root degree 3, internal degree 2) and reported zero logical errors at $d \geq 3$ for bit 0 only. This project identifies a structural asymmetry: internal tie-breaking at 2-child nodes favors logical 0, collapsing the energy barrier for logical 1 to a **constant** $B = 2$ at all depths — rendering logical 1 essentially unprotected. The original claims are valid only for the tested state.

We resolve this by switching to $p = 3$ (ternary tree, all nodes have exactly 3 children). Odd branching eliminates all tie-breaking. Both logical states receive identical exponential protection $B(d) = 2^d$. At $d = 7$ ($2{,}187$ leaves), zero logical errors across $36{,}000$ total trials at $p_{\text{err}} \leq 0.40$ (Wilson 95% CI upper bound: $0.0019$). At $d = 8$, zero errors across $18{,}000$ trials (CI upper: $0.0038$).

The project extends across 7 sprints (28 tasks) and delivers 8 novel computational findings beyond [1]: (F1) $p=2$ asymmetry exhaustively verified; (F2) $p=5,7$ symmetric with barrier formula confirmed; (F3) classical repetition code beats tree at i.i.d. noise (honest baseline); (F4) tree beats classical under correlated noise (first practical advantage); (F5) multi-bit encoding scales throughput ($7.29\times$ at 9 bits); (F6) $q$-ary scatter achieves $48\times$ LER reduction at zero qubit cost; (F7) balanced trees optimal under i.i.d. noise; (F8) QEC concatenation identifies tree as hierarchical repetition code.

All results are $[\text{CODE-EXECUTED}]$, reproducible with Python 3.10+ (standard library only, seed = 42). Total computational footprint: ~260,000 Monte Carlo trials, 26 files, 4,500+ lines of Python.

## 1. Project Identity

### What This Is

A companion project to Quni-Gudzinas (2026), "Computational Validation of Ultrametric Error Confinement in Bruhat–Tits Tree Quantum Circuits" (Zenodo, DOI: `10.5281/zenodo.20134944`). The original introduced the concept of passive error confinement via hierarchical majority voting on a Bruhat–Tits tree — a geometric structure from $p$-adic mathematics where the ultrametric distance naturally bounds error propagation. The original used $p=2$ and tested only logical bit 0.

### What We Found

The $p=2$ architecture has a structural asymmetry: internal nodes have 2 children (even), requiring tie-breaking. The convention "ties break to 0" favors logical 0. Logical 1 requires only 1 error at any internal node to flip it, collapsing the barrier from $2^d$ to a constant $2$ at all depths.

### What We Built

A $p=3$ (ternary) architecture where every node (including the root) has exactly 3 children. Odd branching eliminates all tie-breaking. Both logical states receive identical exponential protection.

### Why $p=3$ Specifically

$p$ must be prime (Bruhat–Tits tree over $\mathbb{Q}_p$ requires $\mathbb{Z}_p$ to be a discrete valuation ring). The strict BT construction is **never** symmetric for any prime (Theorem 1, companion paper §2.3). Our regular $p$-ary deviation (all nodes have $p$ children, root included) makes every odd prime symmetric. $p=3$ is the smallest odd prime — minimal qubit overhead, identical barrier exponent $2^d$ as $p=2$(b0). $p=5$ and $p=7$ also work but require $36\times$ and $377\times$ more qubits at $d=7$.

## 2. Architecture

### Regular $p$-Ary Tree

Every node has exactly $p$ children. Leaves are at depth $d$. Total leaves: $p^d$. Total nodes: $(p^{d+1} - 1)/(p - 1)$.

### Encoding

All leaves are set to the logical bit value $b \in \{0, 1\}$. This is a passive encoding — no entangling gates, no syndrome measurements, no real-time feedback.

### Decoding (Classical Post-Processing)

Bottom-up majority vote:

1. Each leaf value is read out via fluorescence imaging
2. For each internal node at depth $d-1$: majority of its $p$ child values determines its value
3. Continue upward until the root
4. Root value = decoded logical bit

Since $p$ is odd, ties are impossible — every node has a strict majority.

### Noise Model

I.i.d. bit-flip errors on leaves with probability $p_{\text{err}}$. Internal nodes are not physical — only leaves correspond to atoms. Error injection via $X$-rotation with angle $\theta = 2 \arcsin(\sqrt{p_{\text{err}}})$.

### Barrier Formula

The minimum number of leaf errors required to flip the root majority:

$$B(d) = \lceil p/2 \rceil^d$$

For $p=3$: $B(d) = 2^d$.

For $p=5$: $B(d) = 3^d$.

For $p=7$: $B(d) = 4^d$.

**Proof:** Constructive induction. At depth 1, need $\lceil p/2 \rceil$ leaf errors (strict majority change). At depth $d+1$, each internal node at depth 1 has $p$ children that are subtrees of depth $d$. Each subtree requires $B(d)$ errors to flip. Need $\lceil p/2 \rceil$ subtrees to flip the root. Total: $\lceil p/2 \rceil \cdot B(d) = \lceil p/2 \rceil^{d+1}$.

### Tie-Free Guarantee

All odd $p$ yield tie-free architectures in the regular $p$-ary construction. All even $p$ have ties at every node.

### Finding 1: $p=2$ Asymmetry — Exhaustively Verified

**Status:** $[\text{CODE-EXECUTED}]$

The original strict BT $p=2$ tree (root degree 3, internal degree 2) was analyzed exhaustively through $d=3$ (4,096 total leaf patterns):

|:------|:-------|:----------|:----------|:------|

Bit 0: exponential protection $B(d) = 2^d$. Bit 1: constant $B(d) = 2$ at all $d \geq 2$.

The regular $p$-ary $p=2$ tree (all nodes have 2 children) is **even worse**:

A single leaf error anywhere propagates to flip the root when encoded as logical 1.

**Implication:** The original [1] results are valid for bit 0 only. Bit 1 would have produced near-random LER at all depths. The error confinement was **unidirectional**.

**Interpretation:** The tree's value is NOT raw error-correction efficiency. It lies in geometric structure, ultrametric mathematics, natural physical mapping, and — critically — advantage under correlated noise (Finding 4).

### Finding 4: Tree Beats Classical Under Correlated Noise

**Status:** $[\text{CODE-EXECUTED}]$, 1,000 trials per condition

Two-stage correlated noise model: (1) i.i.d. flips with $p_{\text{base}}$, then (2) for each flipped leaf, flip $k=2$ nearest DFS neighbors with probability $p_{\text{corr}}$.

**Crossover points — $p_{\text{base}}$ where Tree LER $<$ Classical LER:**

| $(p,d)$ | $N$ | $p_{\text{corr}}=0.25$ | $p_{\text{corr}}=0.50$ | $p_{\text{corr}}=0.75$ |
|:--------|:----|:----------------------|:----------------------|:----------------------|
| (3,3) | 27 | — | $\geq 0.30$ | $\geq 0.25$ |
| (3,4) | 81 | $\geq 0.35$ | $\geq 0.25$ | $\geq 0.20$ |
| (5,3) | 125 | $\geq 0.35$ | $\geq 0.30$ | $\geq 0.20$ |

**Three scaling trends:** Higher $p_{\text{corr}}$ favors the tree; higher $d$ favors the tree; larger $p$ favors the tree. At $p_{\text{corr}}=0.75$, the tree wins at $p_{\text{base}} \geq 0.20$ for all tested configurations.

**Mechanism:** Clustered errors in one subtree are contained by hierarchical voting — they affect only that subtree's vote, and the other $\lceil p/2\rceil - 1$ sibling subtrees remain correct. In classical repetition, clustered errors in adjacent bits concentrate the error budget, efficiently flipping the global majority.

**This is the first computational evidence that the tree architecture provides genuine practical advantage over classical codes.**

### Finding 5: Multi-Bit Encoding Scales Throughput

**Status:** $[\text{CODE-EXECUTED}]$

Partition the tree at split depth $k$. Each of the $p^k$ subtrees at depth $k$ encodes one logical bit independently. Total logical bits $= p^k$, leaves per bit $= p^{d-k}$, barrier per bit $= \lceil p/2\rceil^{d-k}$.

| Split $k$ | Logical bits | Leaves/bit | Barrier/bit | Correct bits/trial at $p_{\text{err}}=0.40$ |
|:----------|:-------------|:-----------|:------------|:--------------------------------------------|
| 0 (single) | 1 | 243 | 32 | 0.975 |
| 1 | 3 | 81 | 16 | 2.71 |
| 2 | 9 | 27 | 8 | **7.29** |

Independence verified: max pairwise deviation $< 5 \times 10^{-5}$ — bits in different subtrees are truly independent.

Nine bits at $B=8$ per bit achieve $7.29\times$ the correct-bit throughput of single-bit encoding. The cost is weaker per-bit protection, but the net information throughput increases significantly.

### Finding 6: $q$-Ary Scatter — $48\times$ LER Reduction at Zero Quibit Cost

**Status:** $[\text{CODE-EXECUTED}]$, 500 trials per condition

Binary ($q=2$) encoding is the worst case: every flipped leaf targets the one wrong symbol. In a $q$-ary alphabet ($q > 2$), a flipped leaf scatters randomly across $q-1$ wrong symbols, making it harder for any single wrong symbol to achieve plurality.

At $q=3$, $d=3$: $48\times$ LER reduction vs binary. At $q=5$, zero errors at all tested depths.

For $q=3$, $d=3$: $B_{\text{rand}} \approx 4^3 = 64$ vs adversarial $B_{\text{adv}} = 2^3 = 8$ — an 8× effective barrier increase.

### Finding 7: Balanced Trees Optimal Under I.I.D. Noise

**Status:** $[\text{CODE-EXECUTED}]$

Dynamic tree restructuring (unbalanced depth allocation) was tested against uniform-depth allocation at matched utility weights. Balanced ($[2,2,2]$) outperforms unbalanced ($[3,2,1]$) by 36–45% in utility per leaf.

The uniform hierarchical structure is naturally optimal for i.i.d. noise. Dynamic restructuring would only help under heterogeneous or correlated conditions.

### Finding 8: QEC Concatenation Is Redundant

**Status:** $[\text{CODE-EXECUTED}]$

Tree concatenated with inner $M$-bit repetition code at each leaf. At matched total qubit counts ($p^d \times M$), pure classical repetition wins at all three tested budgets (27, 81, 243 qubits). The tree IS already a hierarchical repetition code — adding flat repetition at the leaf level is redundant.

## 5. Correlated Noise — The First Practical Advantage

### Why It Matters

The classical baseline comparison (Finding 3) showed that the tree architecture underperforms classical repetition at i.i.d. noise. This is a fair and honest result, but it could be misinterpreted as "the tree provides no benefit."

The correlated noise experiments demonstrate the opposite: under **realistic, spatially correlated noise** — errors that cluster in physical space — the tree's hierarchical structure provides genuine, measurable advantage.

### The Model

Two-stage correlated bit-flip process:

**Stage 1:** Independent flips. Each leaf flips with probability $p_{\text{base}}$.
**Stage 2:** Neighbor propagation. For each leaf flipped in Stage 1, flip up to $k=2$ nearest neighbors in DFS order with probability $p_{\text{corr}}$.

This models physical crosstalk, environmental fluctuations, or Rydberg-mediated error propagation in neutral atom arrays.

### Why the Tree Wins

In the tree, clustered errors in one subtree are **contained** — they affect only that subtree's majority vote. The other $\lceil p/2\rceil - 1$ sibling subtrees remain correct. The root only flips if a majority of its children are flipped — and clustered errors typically affect only one child's subtree.

In classical repetition, clustered errors in adjacent bits **concentrate** the error budget in one region. If errors cluster around bit index $i$, the bits in $[i-k, i+k]$ are all corrupt, efficiently contributing to a global majority flip.

### Scaling Trends

| $p_{\text{corr}} \uparrow$ | Tree advantage $\uparrow$ | Crossover $p_{\text{base}} \downarrow$ |
|:--------------------------|:------------------------|:--------------------------------------|
| 0.00 | No advantage (classical always wins) | — |
| 0.25 | Marginal (tree wins at 1/7 $p_{\text{base}}$ values for $d=3,4$) | $\geq 0.35$ |
| 0.50 | Moderate (tree wins at 2-3/7 $p_{\text{base}}$ values) | $\geq 0.25$–$0.30$ |
| 0.75 | Strong (tree wins at 3-4/7 $p_{\text{base}}$ values) | $\geq 0.20$ |

Higher depth ($d \uparrow$) and larger branching factor ($p \uparrow$) both amplify the tree's advantage — more levels in the hierarchy provide more containment, and more sibling subtrees mean stricter majority requirements.

## 6. $q$-Ary Generalization — Error Suppression Through Symbol Scatter

### The Insight

In binary encoding ($q=2$), every flipped leaf ALWAYS targets the one wrong symbol. This is the worst-case scenario for the adversary. If we use $q=3$ symbols $\{0, 1, 2\}$ instead, a flipped leaf has only a $1/(q-1) = 50\%$ chance of targeting any specific wrong symbol.

### The Mechanism

Consider a single internal node with $p=3$ children, all set to symbol $0$:

- **Binary ($q=2$):** Every flipped child becomes $1$. Two flips are needed for $1$ to win majority.
- **Ternary ($q=3$):** A flipped child becomes $1$ or $2$ with 50% probability each. For $1$ to win majority, at least 2 flips must BOTH target $1$. The probability of this is $(0.5)^2 = 0.25$ times the binary scenario.

At depth $d$, this scatter effect compounds: the random-scatter effective barrier is approximately $(\lceil p/2\rceil \cdot (q-1))^d$, compared to the adversarial barrier $\lceil p/2\rceil^d$.

### Physical Implementation

No additional hardware is required. Alkali atoms (Rb, Cs) naturally support encoding in hyperfine levels:
- $^{87}$Rb: $F=1,2$ hyperfine manifold → $q=3$–$5$ distinguishable states
- $^{133}$Cs: $F=3,4$ hyperfine manifold → $q=5$–$7$ distinguishable states
- Alkaline-earth atoms ($^{87}$Sr, $^{171}$Yb): nuclear spin $I=9/2$, $I=1/2$ → $q=10+$ distinguishable states

The scatter mechanism converts this EXISTING physical capacity into error suppression. No additional atoms, gates, or control lines are needed.

## 7. Classical Baseline and Honest Comparisons

### The Honest Baseline Principle

Throughout this project, we have deliberately sought out negative results that challenge the tree architecture's claimed advantages. The goal is not to advocate for the tree but to **understand exactly where and why it provides value**. Four negative findings emerged:

1. **Classical repetition beats tree at i.i.d. noise** (§7.6) — honest admission that the tree is not a better error-correcting code for independent errors
2. **Balanced trees optimal under i.i.d.** (Sprint 5) — dynamic restructuring provides no benefit for uniform noise
3. **QEC concatenation is redundant** (§7.8) — the tree IS a hierarchical repetition code; concatenating is pointless
4. **Regular $p$-ary $p=2$ is worse than strict BT** — $B(b1)=1$ instead of $2$, making asymmetry even more severe

### Where the Tree Actually Wins

The tree's genuine advantages emerge in two specific regimes:

1. **Correlated noise** (§7.6.1): Errors that cluster spatially — the dominant noise mode in neutral atom arrays with Rydberg-mediated interactions
2. **$q$-ary encoding** (§7.7): Exploits existing atomic internal structure for error suppression at zero additional qubit cost

Additionally, the tree provides **theoretical value**: a concrete computational application of $p$-adic geometry and Bruhat–Tits buildings, connecting error correction to ultrametric analysis in a novel way.

4. **Read out:** Fluorescence imaging, classify each atom as bright ($|1\rangle$) or dark ($|0\rangle$)
5. **Post-process:** Classical hierarchical majority vote (4 steps, no quantum operations)

## Appendix B — Theorem 1 (Universal BT Asymmetry)

**Statement:** For every prime $p$, the strict Bruhat–Tits rooted tree contains nodes with an even number of children, at which majority-vote tie-breaking is required.

**Proof:** The strict Bruhat–Tits tree for $\text{SL}(2, \mathbb{Q}_p)$ is a $(p+1)$-regular infinite tree. When rooted, the root has $p+1$ children (all neighbors in the full tree), and internal nodes have $p$ children (one neighbor is "up" toward the root).

- Case 1: $p = 2$. Internal nodes have $p = 2$ children (even). Root has $p+1 = 3$ (odd).
- Case 2: $p \geq 3$ (odd primes). $p$ is odd $\implies p+1$ is even $\implies$ root has even children.

**Corollary:** Asymmetry is universal — it moves from internal nodes ($p=2$) to the root ($p \geq 3$). There is no prime $p$ for which the strict construction yields a tie-free tree.
